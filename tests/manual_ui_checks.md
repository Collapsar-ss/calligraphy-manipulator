# 实际鼠标交互检查

在 Windows 原生 MATLAB 窗口中通过 computer-use 操作，未打开或运行 Simulink。

- 将第 3 点从 (40%, 1.2 mm) 拖动至约 (44.61%, 1.638 mm)：表格、曲线、路径控制点与三维深度联动更新。
- 将第 1 点同时向右和向上拖动：进度保持 0%，深度变为约 0.348 mm。
- 将第 3 点拖过第 4 点并超过最大深度：进度限制为 59%（第 4 点为 60%），深度限制为 2 mm。
- 点击“恢复本笔”：六点恢复为默认配置。

检查发现并修复：MATLAB 坐标轴默认交互干扰拖动。关闭该轴默认交互，使用窗口级鼠标事件；拖动时直接更新图形对象，不重建正在被拖动的点。
